Query live databases read-only, without importing.

```bash
tracebook source add shop --type postgres --env SHOP_URL
tracebook source add legacy --type sqlite --path data/legacy.sqlite
tracebook source list
tracebook source remove shop
```

- Types: `postgres`, `mysql`, `sqlite`, `duckdb`. Postgres/MySQL take `--env VAR`: the URL stays in the environment variable, not in the workspace. SQLite/DuckDB files take `--path` (relative to the workspace) or `--env`.
- `add` tests the connection before saving.
- SQL blocks read `shop.<schema>.<table>`, read-only. Filter and aggregate in that SQL block; Python blocks read its result, never the source.

A SQLite file can also be imported as a snapshot: `tracebook import data/olist.sqlite` (used by the [Olist examples](/examples)).
