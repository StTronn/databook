The review loop between you and the agent, and rerunning on new data.

## Comments

1. In `databook dev`, leave a comment on a block: "count per user, not per session".
2. On its next turn the agent runs `databook comments`, changes the notebook, then:

```bash
databook comments resolve 3 --note 'counts distinct user_id now'
databook comments --all     # include resolved
```

The note is shown to you in the viewer. Comments live in `.databook/comments.json`.

## Diff

```bash
databook diff
```

Lists per-block changes between the last two runs with a different notebook or data: which blocks and numbers moved. The agent uses it to tell you what changed after an edit.

## Rerun on new data

```bash
databook import data/payments_nov.xlsx
databook check
databook diff
```

The notebook is the same file; only the data changed.
