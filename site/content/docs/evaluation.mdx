Does the CLI and skill help an agent answer correctly, and leave a notebook behind?

Databook is evaluated on public benchmark tasks it did not write ([Spider2-lite](https://github.com/xlang-ai/Spider2)), run with [Harbor](https://docs.harborframework.com/), comparing plain Claude Code, Claude Code with a data-analysis playbook, and Claude Code with the playbook plus Databook.

Method, tasks, results and how to run them: [README → Evaluation](https://github.com/StTronn/databook#evaluation).
